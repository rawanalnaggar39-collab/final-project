# Capitals Explorer
A simple website that displays capitals of some countries.
## 💡 Story & Motivation
I always love to travel and learn new things about countries so I wanted to build an engaging and visually appealing web application that allows users to explore key facts and information about major world capitals—including Cairo, Riyadh, Moscow, Washington D.C., and more. 
 
 ## 🛠️ Built With
 - *HTML5* - Structure and semantic content
- *CSS3* - Custom styling, layout design, and responsiveness
- *JavaScript* - Dynamic functionality and UI interaction
